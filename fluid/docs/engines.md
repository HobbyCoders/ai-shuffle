# Engine capabilities

All three engines accept operations and emit Fluid events, but an accepted
operation does not imply the same behavior on every backend. The native loop
calls provider APIs directly. The delegated loop runs Claude Code in
stream-JSON mode. The ACP loop drives an external agent over stdio; AI Shuffle
constructs it for Antigravity in [`_connect_antigravity`](../../app/core/provider/harness_adapter.py).
The standalone Fluid config loader selects native or delegated, not ACP.

**Supported** means Fluid implements the operation or a bridge for it under
the stated conditions. **Host-provided** means the embedding or subprocess
owns the behavior. **Not supported** means this Fluid engine does not expose it.
`Resume` below is the Fluid op for retrying an unanswered prompt, not the
CLI's `--resume` option for reopening a stored session. On native and ACP, a
partial reply kept by `Interrupt` is marked interrupted, so an immediate
`Resume` steps back past it and re-runs the prompt under it.

| Capability | Native | Delegated Claude CLI | ACP (Antigravity) |
|---|---|---|---|
| `Resume` | **Supported.** Retries from the stored unanswered user node (also looks behind a reply marked interrupted). [`NativeLoop._run_turn_inner`](../fluid/engine/native.py). | **Not supported.** `submit` rejects the op. `_build_argv` can still pass a saved `--resume` handle to reopen the CLI conversation. [`DelegatedLoop`](../fluid/engine/delegated.py). | **Supported.** `_run_turn` resends text/images from the unanswered user node via `session/prompt`, stepping back past every node an interrupted turn stored. Separately, `_ensure_process` can reopen the agent session via `session/resume`. [`AcpLoop`](../fluid/engine/acp/loop.py). |
| Interrupt / cancel | **Supported.** `submit(Interrupt)` sets a flag read by the interruptible provider and tool waits. [`_provider_chunks_interruptible`, `_dispatch_tool_interruptible`](../fluid/engine/native.py). | **Supported.** Sends the CLI an interrupt control request. [`submit`, `_send_interrupt`](../fluid/engine/delegated.py). | **Supported.** Sends `session/cancel`; cancellation is reported as `Interrupted` when the agent returns `cancelled`. [`_cancel_remote`, `_drive`](../fluid/engine/acp/loop.py). |
| Mid-turn steering | **Supported.** Queues `Steer` for a tool result. An undelivered steer is dropped at turn end. [`submit`, `_agent_loop`](../fluid/engine/native.py). | **Supported.** `_deliver_steer` hands text to the CLI at a tool boundary or via stdin, depending on the active lane. [`DelegatedLoop`](../fluid/engine/delegated.py). | **Supported.** `_steer` sends a second `session/prompt` while steering is open. The remote agent decides how to take it. [`AcpLoop._steer`](../fluid/engine/acp/loop.py). |
| Background completion and wake | **Supported.** The host runs the worker; the engine tracks receipts, accepts `BackgroundTaskFinished`, parks with pending jobs, and schedules a wake turn unless suppressed. [`NativeLoop.submit`](../fluid/engine/native.py), [`BackgroundLifecycleMixin`](../fluid/engine/background.py). | **Supported.** Same receipt and wake lifecycle for Fluid-hosted work, not a promise about Claude's own tasks. [`DelegatedLoop.submit`](../fluid/engine/delegated.py), [`BackgroundLifecycleMixin`](../fluid/engine/background.py). | **Host-provided.** `BackgroundTaskFinished` is a no-op in `submit`; the host owns the wake queue. [`AcpLoop.submit`](../fluid/engine/acp/loop.py), [`prepare_background_completions`](../../app/core/provider/harness_adapter.py). |
| Fork / rewind | **Supported.** Both ops move the session head; existing nodes remain in the tree. Refused with `RuntimeError` while a turn is running. [`NativeLoop.submit`](../fluid/engine/native.py). | **Not supported.** The ops raise `NotImplementedError`. [`DelegatedLoop.submit`](../fluid/engine/delegated.py). | **Not supported.** The ops raise `NotImplementedError`; a parent on a Fluid transcript node cannot rewind the agent's own conversation. [`AcpLoop.submit`, `_run_turn`](../fluid/engine/acp/loop.py). |
| Fluid code mode | **Supported.** When configured, `build_engine` wires the kernel and `NativeLoop.__init__` registers code-mode tools. [`build_engine`](../fluid/config/loader.py), [`NativeLoop`](../fluid/engine/native.py). | **Not supported.** `caps.code_mode` is false; the CLI suppresses its code-mode addendum. [`DelegatedLoop.caps`](../fluid/engine/delegated.py), [`code_mode_addendum`](../fluid/cli/prompt.py). | **Not supported.** `caps.code_mode` defaults to false and the ACP adapter has no code-mode setup. [`AcpLoop.caps`](../fluid/engine/acp/loop.py), [`EngineCaps`](../fluid/engine/base.py). |
| Compaction ownership | **Supported.** Fluid manages the request view and manual compaction. [`_agent_loop`, `_run_manual_compaction`](../fluid/engine/native.py), [`Compactor`](../fluid/context/compaction.py). | **Host-provided.** Claude owns the active context and compaction boundary; Fluid observes it and can supply summaries through the optional mod. [`_track_main_compaction`, `_compact_mod_messages`](../fluid/engine/delegated.py). | **Host-provided.** The agent owns its context; Fluid forwards prompts and doesn't run its compaction ladder on this path. Whether and how Antigravity compacts internally cannot be determined from [`AcpLoop._drive`](../fluid/engine/acp/loop.py). |
| Permission prompts | **Supported.** `_gated_call` checks permissions and `_await_permission` emits a request for the host to answer. [`NativeLoop`](../fluid/engine/native.py). | **Supported.** CLI `can_use_tool` requests are bridged to host decisions using the stdio prompt tool. [`_build_argv`, `_handle_permission`](../fluid/engine/delegated.py). | **Supported.** Maps `session/request_permission` to a Fluid request when policy or mode hasn't already decided it. [`_on_request`, `_permission`](../fluid/engine/acp/loop.py). |
| Hooks | **Supported.** Fluid runs configured hooks around tools, sessions, turns and compaction. [`_gated_call`, `_emit_session_start`, `_start_and_loop`, `_emit_pre_compact`](../fluid/engine/native.py), [`build_engine`](../fluid/config/loader.py). | **Supported.** Fluid registers for selected CLI hook events; the bundled bridge handles hooks for its own tools. [`_initialize_cli_hooks`, `_start_bundled_server`](../fluid/engine/delegated.py). | **Supported for bridged tools only.** The MCP bridge receives a host-supplied `HookBus`; native agent tool and turn hooks are not forwarded by this adapter. [`_start_bridge`, `_on_request`](../fluid/engine/acp/loop.py), [`_gate_call`](../fluid/tools/mcp/bundled_server.py). |
| Built-in tool availability | **Supported.** Loads Fluid built-ins from a registry. Tool allow and deny lists and wiring control what is advertised; the engine evaluates permission policy at dispatch. [`build_engine`](../fluid/config/loader.py), [`_tools_api`, `_dispatch_tool`](../fluid/engine/native.py). | **Host-provided.** Claude announces its own tools; permitted Fluid registry built-ins can be exposed as MCP tools rather than replacing Claude's tools. [`_map_until_result`, `_start_bundled_server`](../fluid/engine/delegated.py). | **Host-provided.** The agent supplies its own built-ins. Host-provided Fluid built-ins can be offered through MCP, not as native agent tools. [`AcpLoop`, `_start_bridge`, `bridged_tools`](../fluid/engine/acp/loop.py). |
| MCP tools | **Supported.** `_connect_mcp_once` connects configured servers and adds their tools to the registry. [`NativeLoop`](../fluid/engine/native.py). | **Supported.** Passes the bundled and configured servers via `--mcp-config` when a bridge config is built; one-shot mode omits external servers. [`_start_bundled_server`, `_build_argv`](../fluid/engine/delegated.py). | **Supported.** Passes the bundled bridge and configured servers. Stdio is assumed; HTTP and SSE require the agent to advertise those transports. [`AcpLoop._mcp_servers`](../fluid/engine/acp/loop.py), [`AgentInfo.mcp_transports`](../fluid/engine/acp/client.py). |
| Deferred tool schemas | **Supported.** `_tools_api` uses loaded specs; `ToolSearch` can load a deferred schema. [`NativeLoop`](../fluid/engine/native.py), [`tool_search.py`](../fluid/tools/builtins/tool_search.py). | **Supported.** With a `bridge_deferred` predicate, the bundled server marks tools for Claude's ToolSearch on compatible CLI versions. [`_start_bundled_server`](../fluid/engine/delegated.py), [`serve_registry_socket`, `_answer`](../fluid/tools/mcp/bundled_server.py). | **Supported.** With a `deferred` predicate, the bridge hides those tools from the direct list and exposes `LoadTool` and `CallTool` proxies. [`_start_bridge`, `bridged_tools`, `deferred_tools`](../fluid/engine/acp/loop.py). |
| Usage reporting | **Supported.** Emits `Usage` for most calls and aggregates terminal totals. Some discarded retries (such as a stream cut inside tool arguments) contribute to the totals without emitting `Usage`. Exposes a context breakdown. [`_agent_loop`, `get_context_usage`](../fluid/engine/native.py). | **Supported.** Maps CLI usage and result frames; reports turn cost as the delta of the CLI's cumulative cost and can ask the CLI for context usage. [`StreamJsonMapper`](../fluid/engine/delegated_proto.py), [`get_context_usage`](../fluid/engine/delegated.py). | **Supported when reported by the agent.** `_usage` reads prompt-result token counts and a USD usage update if provided; `get_context_usage` returns `None`. `num_model_calls` is a 0/1 proxy based on mapped output, not a count of internal model calls. [`_drive`, `_usage`, `get_context_usage`](../fluid/engine/acp/loop.py). |

[`test_engine_capabilities.py`](../tests/unit/test_engine_capabilities.py) pins
resume, interruption, background completion and tool ownership using scripted
provider, Claude CLI and ACP fakes. It doesn't establish which tools or usage
fields a particular installed Claude or Antigravity version will report.
