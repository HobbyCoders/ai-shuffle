# AI Shuffle documentation

AI Shuffle is a self-hosted workspace for AI agents, made by HobbyCoders. You run it on your own computer, server or NAS, and use it from a browser, the desktop app or your phone. Agents run on **your own** AI account: you connect a provider with a subscription sign-in or an API key, and that provider bills you directly. AI Shuffle never pays for, resells or sees your AI usage.

AI Shuffle is an independent product. It is not affiliated with, built, endorsed or supported by any AI provider.
