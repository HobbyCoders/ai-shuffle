# File Management

The **Files** page lets you browse your workspace and manage its files without leaving AI Shuffle.

## Use the file browser

Open **Files** in the sidebar. From there you can:

- move between folders with the path at the top;
- show or hide hidden files;
- upload files by dragging them in or with the upload button;
- download a file;
- create, rename and delete files and folders.

A project's own **.git** folder is protected. Nothing in the file browser can change it.

## Files from the agent

When an agent makes a file for you, such as a report, an image or a video, it appears in the chat as a download card. Click it to download the file.

Images and videos the AI tools generate also show up right in the chat.

## Files and API keys

An API key that belongs to a project can only reach files inside that project.

To upload and download files from your own code, see the [Projects API](/docs/api-reference/projects).
