What the proposal changes

  • Twice as fast, and it feels faster still: 450 ms hold + 1200 ms linear (1.65 s total) becomes a 250 ms hold + 520 ms flip — under half a second of perceived motion, so a popover that opens and closes quickly still reads.
  • Easing instead of linear rotation: the leaving flap accelerates in (cubic ease-in, like gravity), the arriving flap decelerates with a slight overshoot-and-settle (ease-out-back), which is what makes a real split-flap read as mechanical.
  • Per-digit stagger (~70 ms): digits cascade left-to-right instead of snapping in lockstep; "9 → 34" reads as a count, not a texture swap.
  • Tiles only where the digit changes: unchanged digits stay plain text instead of getting a boxed card and a midline through them, so most updates animate one or two glyphs rather than the whole string.
  • Real depth: perspective 160 px → 600 px, gradient tile faces, a drop shadow under the moving flap, and the midline drawn only mid-flip so it reads as the card seam.
  • Unchanged behaviours kept: direction-aware flip (up/down), persistence across panel remounts, cross-key/cross-unit suppression, rAF cancellation, and prefers-reduced-motion falls straight back to static text.
