# Support

Support is best effort, with AI Shuffle Cloud customers first. There is no guaranteed response time.

Use the in-app **Report a problem** action so the report includes diagnostic context. Review the report before sending it. When opening a bug issue, include its support report ID, your app version and update channel, installation type, and steps to reproduce. If you cannot open the app or submit a report, say so; you can still file an issue.

Never post secrets in issues or send passwords, API keys, access tokens or sign-in codes. Remove private data from logs and screenshots before sharing them. For account or Cloud support, email support@hobbycoders.com. Report suspected vulnerabilities privately using [SECURITY.md](SECURITY.md).

Start with the [documentation](docs/content/getting-started/_index.md) and [FAQ](https://hobbycoders.com/ai-shuffle/faq). Community discussion is on [Discord](https://hobbycoders.com/discord).
