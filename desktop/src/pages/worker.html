AI Shuffle

Use an external PostgreSQL

AI Shuffle keeps sessions, settings and history in PostgreSQL and runs its own copy for you. Point it at a server you run instead, on this computer or on your network.

This computer has no keyring available, so the password will be stored in a file only your user account can read.

Using the bundled PostgreSQL. Its data lives in the app's data folder; nothing to configure.

Done with the external server?

Setting up an external server

Install PostgreSQL 16 or newer, then create a user and a database for AI Shuffle. In psql:

CREATE USER ai_shuffle WITH PASSWORD 'choose-a-password';
CREATE DATABASE ai_shuffle OWNER ai_shuffle;

If the user exists but the database does not, the button above can create it. Downloads: postgresql.org/download. The external server keeps its own data; switching back to the bundled one returns to the data stored there.
